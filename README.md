# BETORA — симулятор ставок для Minecraft

Демо-проект на чистом HTML/CSS/JavaScript и Cloudflare Pages Functions + D1. Валюта игровая, реальные деньги не используются.

## Перед публикацией
1. Замените `REPLACE_WITH_YOUR_D1_DATABASE_ID` в `wrangler.toml` на ID созданной D1-базы.
2. В Cloudflare Pages задайте переменные окружения `ADMIN_LOGIN` и `ADMIN_PASSWORD` (для production и preview при необходимости). Пароль администратора должен быть не короче 12 символов.
3. Загрузите `schema.sql` в D1 через `npx wrangler d1 execute betora-db --remote --file=./schema.sql`.
4. Привяжите базу к Pages Functions под именем binding `DB`.
5. Папка `.js`/`.html` проекта является корнем статических файлов; сборка не требуется.

## Важные замечания
- Администратор создаётся при первом запросе API, если `ADMIN_LOGIN` и `ADMIN_PASSWORD` заданы. Если пользователь с таким логином уже есть, ему назначается роль администратора.
- После изменения `ADMIN_PASSWORD` пароль существующего аккаунта автоматически не меняется; меняется только роль. Для смены пароля используйте отдельную миграцию/процедуру, не удаляйте пользователя без резервной копии.
- Данные seed-матчей демонстрационные. Это не подтверждённое расписание реальных турниров.
- На Cloudflare Pages `wrangler.toml` должен содержать реальный `database_id`. Не публикуйте секреты в GitHub.
